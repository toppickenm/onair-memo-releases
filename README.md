# OnAir Memo 배포

방송용 메모장 OnAir Memo의 설치 파일을 배포하는 저장소입니다.

## 내려받기

[최신 릴리즈](https://github.com/toppickenm/onair-memo-releases/releases/latest)에서 다음 중 하나를 받으세요.

- `OnAirMemo-Setup-x.y.z.exe`: 설치 버전. 앱을 켤 때 새 버전을 확인하고, 업데이트할지 선택할 수 있습니다.
- `OnAirMemo-Portable-x.y.z.exe`: 설치 없이 실행하는 버전. 자동 업데이트가 없으므로 새 버전은 직접 내려받아 교체합니다.

코드 서명이 없어서 처음 실행할 때 Windows SmartScreen 경고가 나올 수 있습니다. 이때는 **추가 정보 → 실행**을 누르세요.
