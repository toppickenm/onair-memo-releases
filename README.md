# OnAir Memo 배포

방송용 메모장 OnAir Memo의 설치 파일을 배포하는 저장소입니다.

## 설치 방법

### 1. 파일 고르기

[최신 릴리즈](https://github.com/toppickenm/onair-memo-releases/releases/latest) 페이지 아래쪽의 **Assets** 목록에서 하나를 내려받습니다. 대부분은 설치 버전을 쓰시면 됩니다.

| 파일 | 설명 |
|---|---|
| `OnAirMemo-Setup-x.y.z.exe` | **설치 버전 (권장)**. 앱을 켤 때 새 버전을 확인하고 업데이트할 수 있습니다. |
| `OnAirMemo-Portable-x.y.z.exe` | 설치 없이 바로 실행하는 버전. 자동 업데이트가 없습니다. |

`latest.yml`과 `.blockmap` 파일은 자동 업데이트에 쓰이는 파일이므로 내려받지 않아도 됩니다.

### 2. 설치 버전 설치하기

1. 내려받은 `OnAirMemo-Setup-x.y.z.exe`를 실행합니다.
2. **"Windows의 PC 보호"** 창이 나타나면 **추가 정보**를 누른 뒤 **실행**을 누릅니다.
   코드 서명 인증서가 없는 앱이라서 처음 실행할 때 이 경고가 나타납니다.
3. 설치 대상을 고르는 화면에서는 **현재 사용자만** 설치하는 항목을 선택하는 것을 권장합니다.
   이렇게 설치하면 관리자 권한 없이 설치되고, 업데이트도 확인 창 없이 진행됩니다.
4. 설치 폴더는 기본값 그대로 두고 설치를 진행합니다.
5. 설치가 끝나면 바탕 화면과 시작 메뉴에 **OnAir Memo** 바로 가기가 만들어집니다.

### 3. 포터블 버전 사용하기

`OnAirMemo-Portable-x.y.z.exe`를 원하는 폴더에 두고 실행하면 됩니다. 처음 실행할 때 SmartScreen 경고가 나타나면 위의 2단계와 같이 **추가 정보 → 실행**을 누릅니다.
새 버전이 나오면 앱 하단에 다운로드 페이지 링크가 표시됩니다. 새 파일을 내려받아 기존 파일과 바꾸면 됩니다.

### 4. 업데이트

- **v0.4.0 이상을 설치해 두셨다면** 따로 내려받을 필요가 없습니다. 앱을 켜면 하단 알림 막대에 업데이트 안내가 나타나고, **[업데이트]**를 누르면 내려받은 뒤 재시작하여 설치합니다. 방송 모드 중에는 재시작하지 않고, 방송 모드를 끈 뒤에 진행합니다.
- **v0.3.0 이하를 쓰고 계신다면** 업데이트 기능이 없으므로 설치 파일을 받아 한 번 직접 설치해 주세요.
- 어느 경우든 메모 데이터는 그대로 유지됩니다.

### 5. 메모 데이터 위치

메모, 탭, 설정, 추가한 이미지와 폰트는 아래 폴더에 저장됩니다. 설치 버전과 포터블 버전이 같은 폴더를 사용합니다.

```
%APPDATA%\custom-memo-app\memo-data
```

설정(⚙) → **[데이터 폴더 열기]**를 누르면 이 폴더가 바로 열립니다. PC를 옮길 때는 이 폴더를 통째로 복사하면 됩니다.

### 6. 삭제

Windows **설정 → 앱 → 설치된 앱**에서 **OnAir Memo**를 찾아 제거합니다. 앱을 제거해도 메모 데이터 폴더는 남아 있으므로, 메모까지 지우려면 위 폴더를 직접 삭제합니다.
